超大型題庫規劃：100,000,000,000 題

網站已保留大量題庫匯入／匯出功能，但 1,000 億題不能直接塞進單一 HTML 或瀏覽器儲存空間。正式規模需要伺服器、資料庫、分批載入、索引與題目生成服務。以下示範版可管理你匯入的題目，並非已內建 1,000 億道人工編寫題目。

題庫 JSON 格式

每題需包含 stage、grade、subject、question、options、answer、explanation。answer 是 options 的從 0 開始索引（第一個選項為 0）。

[
  {
    "stage": "國中",
    "grade": "國中八年級",
    "subject": "數學",
    "question": "若 2x + 3 = 11，則 x =？",
    "options": ["2", "3", "4", "7"],
    "answer": 2,
    "explanation": "兩邊同減 3 得 2x=8，再除以 2，x=4。",
    "source": "自編練習題"
  }
]
全學段學習挑戰站｜示範版題目為自編練習題，不代表因材網官方題庫。GitHub Pages 可託管此靜態網站，但跨裝置同步與真實多人排行榜需要後端資料庫。
